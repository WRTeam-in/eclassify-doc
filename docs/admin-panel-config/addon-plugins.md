# Add On Plugins

eClassify supports optional Add On Plugins, sold separately on [WRTeam Marketplace](https://marketplace.wrteam.in/), that extend the app with extra features. Plugins are installed and managed from the admin panel's **Plugin Manager**.

## Purchase (WRTeam Marketplace)

- Buy the desired plugin on [WRTeam Marketplace](https://marketplace.wrteam.in/).
- You will receive a **purchase code**, the plugin **zip file**, and documentation.

## Browse Catalog

1. Go to **Admin Panel → Plugin Manager**.
2. Browse the list of available plugins.
3. Click **Install** on the desired plugin.

## Install a Plugin

1. Enter the **purchase code** from your WRTeam Marketplace order.
2. Upload the plugin **zip file**.
3. Submit.

The purchase code is verified, and once confirmed, the plugin is installed and activated automatically.

## Manage Installed Plugins

- The **Installed** tab lists all installed plugins, each with an enable/disable toggle.
- Disabled or unlicensed plugins are automatically deactivated across the site.

## Refresh Catalog

Use the **Refresh Catalog** button to update the plugin list with the latest available versions and descriptions.

:::note
Each plugin has its own purchase code and license, separate from the main eClassify license.
:::
